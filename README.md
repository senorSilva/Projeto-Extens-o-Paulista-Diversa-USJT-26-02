# Paulista Diversa

Projeto de extensão universitária da USJT na Avenida Paulista: um laboratório permanente de acolhimento, informação e cultura para a comunidade LGBTQIA+ da região.

 **Site:** https://paulistadiversa.com.br

## As cinco frentes

| Frente | O que faz |
|---|---|
| Direitos e Justiça | Orientação jurídica e criação de cartilhas para ampliar o acesso à informação. |
| Saúde Mental | Acolhimento psicossocial e rodas de conversa. |
| Memória e Cultura | Preservação de narrativas e criação de exposições multimídia. |
| Urbanismo | Microintervenções e sinalização para tornar o espaço público mais acolhedor. |
| Tecnologia | Mapas digitais interativos e plataformas de dados. |
